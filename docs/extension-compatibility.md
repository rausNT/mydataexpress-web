# Совместимость расширений

DataExpress связывает настольную и веб-реализацию расширения по стабильному
контракту: функции — по `Name`, действия — по `Id`. Текущий Web Server выполняет
действие только при наличии соответствующего web-модуля (`WebExists = True`).

## Стратегия бесшовной миграции

1. Не менять `Name` и `Id`: существующие формы и действия продолжат ссылаться на
   те же расширения.
2. Анализировать исходный Pascal Script до развёртывания.
3. Переносимый код выполнять штатным Pascal Script Web Server.
4. Windows-зависимые операции направлять через провайдеры: документы, файловое
   хранилище, запуск задач, внешние API.
5. Пользовательский интерфейс переводить на асинхронные web-события и окна
   сообщений, не пытаясь эмулировать WinAPI в браузере.

## Аудит существующих модулей

```powershell
node tools/extension-audit.mjs C:\path\to\extensions --output compatibility.json
```

Отчёт выделяет OLE/COM, DLL, ShellExecute, WinAPI, локальные пути, диалоги и
сетевые обращения. Категории:

- `portable` — можно переносить в web-модуль напрямую;
- `review` — требуется адаптация интерфейса или политики доступа;
- `requires-provider` — нужна серверная кроссплатформенная реализация.

OLE и WinAPI нельзя безопасно и одинаково воспроизвести в Linux и браузере.
Совместимость достигается сохранением контракта расширения и заменой реализации,
а не запуском Windows DLL на сервере.

## Что обнаружено в каталоге расширений

В публичном каталоге более 170 расширений. Основные классы совместимости:

| Класс | Примеры | Web-реализация |
|---|---|---|
| Чистые вычисления | строки, суммы, проверки, даты | Pascal Script без изменений алгоритма |
| HTTP/API | DaData, Telegram, QR-сервисы | серверный HTTP-провайдер |
| Документы | Excel/Calc, Word, конвертация | генерация файлов на сервере без OLE |
| Файлы | хранилище, мультивыгрузка | объектное/локальное серверное хранилище и download API |
| Оборудование | сканеры WIA/TWAIN, Bluetooth | локальный companion-agent с защищённым web API |
| Нативная графика | DLL диаграмм, штрихкоды | SVG/Canvas или серверный генератор |
| Desktop UI | меню, окна, управление компонентами | события и компоненты браузерного клиента |

Companion-agent нужен только там, где браузер по модели безопасности не имеет
прямого доступа к USB/WIA/TWAIN или другому локальному оборудованию. Обычные
вычисления, файлы, документы и HTTP-интеграции должны работать без Windows.
