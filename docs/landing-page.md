# Стартовая страница подключений

Корневой адрес DataExpress Web Server (`/`) теперь служит точкой входа, а не
только индикатором запущенного процесса. Пользователь может ввести имя
подключения из `dxwebsrv.cfg` и перейти к штатной странице входа.

Имена подключений следуют официальному формату DataExpress: латинские буквы,
цифры и `_`, регистр не имеет значения. Например, секция `[DemoDB]` открывается
по адресу `/demodb/`. Подробное описание секций приведено в
[официальной документации Web Server](https://www.wiki.mydataexpress.ru/web%3Aweb).

## Публичный список

По умолчанию сервер не перечисляет имена подключений. Форма ввода остаётся
доступной, но посетитель должен знать alias. Чтобы показать настроенные
подключения карточками, добавьте в секцию `[Server]`:

```ini
[Server]
ShowConnections=True
```

После изменения перезапустите `dxwebsrv`. В карточки попадают только допустимые
alias. Пути `Database`, `Templates`, пароли `DBPwd` и `ServiceId` никогда не
включаются в HTML стартовой страницы.

Для публичного сервера оставьте `ShowConnections=False`, если даже имена баз не
должны перечисляться. Независимо от этой настройки каждая база по-прежнему
требует штатную авторизацию DataExpress.

## Проверка

Локальный preview показывает пример `DemoDB`:

```powershell
$env:DX_PORT = '8090'
npm run dev
```

Откройте `http://127.0.0.1:8090`. Проверки шаблона, маршрутизации alias,
адаптивности и отсутствия чувствительных полей входят в `npm test`; Windows CI
дополнительно собирает реальный Pascal-бэкенд.
