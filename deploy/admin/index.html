Базы DataExpress

Загрузите `.DXDB`, `.FDB` или официальный `.DXDB.zip`. После проверки база появится на стартовой странице.

Ключ хранится только во вкладке браузера. Для рабочих баз включите HTTPS: без него содержимое файла передаётся открыто.
